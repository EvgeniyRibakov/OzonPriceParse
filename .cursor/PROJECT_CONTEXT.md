## Текущее состояние проекта

**Версия:** 0.1.0  
**Статус:** Начальная настройка проекта

## Архитектура

### Структура
- `src/agents/` - ИИ-агенты для различных задач
- `src/utils/` - Утилиты (HTTP клиент, логирование)
- `src/config/` - Конфигурация через Pydantic Settings
- `tests/` - Unit тесты

### Технологии
- Python 3.10+
- Async/await для I/O операций
- Pydantic для валидации конфигурации
- Loguru для логирования
- Pytest для тестирования
- HTTPX для HTTP запросов

## Важные решения

### ИИ-агенты
- Базовый класс `BaseAgent` для всех агентов
- Каждый агент независим и переиспользуем
- Обработка ошибок на уровне базового класса

### Конфигурация
- Все настройки через переменные окружения
- Pydantic Settings для валидации
- Файл `.env` не коммитится в git
