# Настройка Telegram бота

## Получение токена бота

1. Откройте Telegram и найдите бота **@BotFather**
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: "Ozon Parser Bot")
   - Введите username бота (должен заканчиваться на `bot`, например: `ozon_parser_bot`)
4. BotFather отправит вам токен вида: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`
5. Скопируйте токен и добавьте его в файл `.env`:
   ```env
   TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
   ```

## Настройка пароля

1. Придумайте пароль для доступа к боту (например: `my_secure_password_123`)
2. Добавьте его в файл `.env`:
   ```env
   TELEGRAM_BOT_PASSWORD=my_secure_password_123
   ```

## Запуск бота

1. Активируйте виртуальное окружение:
   ```bash
   venv\Scripts\activate
   ```

2. Запустите бота:
   ```bash
   python run_bot.py
   ```

3. Найдите вашего бота в Telegram (по username, который вы указали)

4. Отправьте `/start` и введите пароль

## Команды бота

- `/start` - Начать работу с ботом
- `/parse` - Запустить парсинг цен
- `/status` - Статус последнего запуска
- `/logs` - Последние логи
- `/download` - Скачать последний файл
- `/guide` - Гайд по установке с нуля
- `/settings` - Текущие настройки
- `/logout` - Выйти из аккаунта

## Безопасность

⚠️ **Важно**: 
- Не публикуйте токен бота и пароль в открытом доступе
- Не коммитьте файл `.env` в git (он уже в `.gitignore`)
- Используйте сложный пароль для доступа к боту
