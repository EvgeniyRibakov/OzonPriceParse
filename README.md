# Ozon Price Parser

Автоматизированный парсер цен с Ozon Seller через браузерную автоматизацию.

## Описание

Проект автоматизирует процесс входа в личный кабинет Ozon Seller, прохождения двухфакторной аутентификации и скачивания отчета с ценами товаров в формате XLSX.

## Особенности

- ✅ Полная визуализация процесса в браузере
- ✅ Имитация человеческого поведения с задержками
- ✅ Интерактивный ввод кодов 2FA
- ✅ Подробное логирование всех действий
- ✅ Обработка ошибок с остановкой и уведомлением

## Требования

- Python 3.10+
- Playwright (браузеры устанавливаются автоматически)

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd OzonPriceParse
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/Mac
source venv/bin/activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Установите браузеры для Playwright:
```bash
playwright install chromium
```

5. Создайте файл `.env` на основе `env.example`:
```bash
cp env.example .env
```

## Настройка

Отредактируйте файл `.env`:

```env
# Ozon Seller настройки
OZON_START_URL=https://seller.ozon.ru/app/products?token=YOUR_TOKEN
PHONE_NUMBER=+79966444210

# Задержки (в секундах) для имитации человеческого поведения
DELAY_BEFORE_CLICK=1.5
DELAY_AFTER_CLICK=2.0
DELAY_BEFORE_TYPE=0.8
DELAY_AFTER_TYPE=1.2
DELAY_BETWEEN_KEYS=0.1
DELAY_PAGE_LOAD=3.0
```

## Использование

Запустите скрипт:

```bash
python -m src.main
```

Или через run.py:

```bash
python run.py
```

## Процесс работы

1. Запуск браузера (видимый режим)
2. Переход по начальной ссылке
3. Нажатие кнопки "Войти" (если требуется)
4. Ввод номера телефона
5. Выбор альтернативного способа входа
6. **Запрос кода из пуш-уведомления** (интерактивный ввод)
7. Обработка дополнительной проверки (если требуется)
8. Нажатие кнопки "Скачать шаблоны"
9. Ожидание скачивания файла XLSX

## Логирование

Все действия логируются в:
- Консоль (краткий формат)
- Файлы в папке `logs/` (подробный формат с датами)

## Важные замечания

⚠️ **Внимание**: Ozon имеет хорошую защиту от ботов. Скрипт использует:
- Задержки между действиями
- Посимвольный ввод текста
- Имитацию человеческого поведения

При любой ошибке скрипт останавливается и выводит сообщение в консоль.
