# OzonPriceParse

Проект для быстрого парсинга цен товаров с Ozon. MVP цель: 5-7 минут на ~1500 товаров с приоритетом на скорость, устойчивость к блокировкам и минимальные затраты.

## Структура проекта

```
OzonPriceParse/
├── src/
│   ├── agents/          # ИИ-агенты
│   ├── utils/           # Утилиты
│   ├── config/          # Конфигурация
│   └── main.py          # Точка входа
├── tests/               # Тесты
├── data/                # Данные (не в git)
├── logs/                # Логи (не в git)
├── requirements.txt     # Зависимости
└── README.md
```

## Установка

1. Клонировать репозиторий
2. Создать виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

3. Установить зависимости:
```bash
pip install -r requirements.txt
```

4. Создать файл `.env` на основе `env.example` с необходимыми переменными окружения:
```bash
cp env.example .env
# Затем отредактировать .env и заполнить необходимые значения
```

## Использование

```bash
# Активировать виртуальное окружение
venv\Scripts\activate  # Windows
source venv/bin/activate  # Linux/Mac

# Запустить (рекомендуется)
```

## Контекст проекта

**Версия:** 0.1.0  
**Статус:** MVP разработка

### Цель проекта
Разработать быстрый и недорогой парсер цен товаров с Ozon для MVP:
- **Целевая скорость:** 5-7 минут на ~1500 товаров
- **Приоритеты:** скорость, устойчивость к блокировкам, минимальные затраты
- **Этап MVP:** только сбор цен (без обновления)

### Текущая ситуация
- **Существующий агент:** https://github.com/EvgeniyRibakov/upgrade_Makar-s_agent
  - Текущая скорость: 45-50 минут (цель: 15-20 минут)
  - Уже работает: 600 товаров за 15-20 минут
- **Пробовали (не сработало):**
  - Selenium/headless - Ozon блокирует
  - Ротация куки/перенос сессий - не работает
- **Идея для проверки:** ручной логин в браузере + открытие новых вкладок (сохраняют авторизацию)

### Исследование Ozon Seller API
**Вывод:** API не подходит для получения финальной цены с СПП и бонусами
- `marketing_price` отключено с 12.11.2025
- Нет поля для СПП (скидка постоянного покупателя)
- Нет поля для бонусных скидок Ozon
- Доступно: `price`, `marketing_seller_price`, `old_price` и др.
- Ограничения: только свои товары, batch до 1000 товаров за вызов

**Альтернативы:**
1. Ускорить текущий агент до 15-20 минут
2. Попробовать подход с ручным логином + вкладками
3. Работа с Excel-отчетами из ЛК (если доступны)

### Архитектура
- `src/agents/` - ИИ-агенты для различных задач (базовый класс `BaseAgent`)
- `src/utils/` - Утилиты (HTTP клиент с retry логикой, структурированное логирование)
- `src/config/` - Конфигурация через Pydantic Settings
- `tests/` - Unit тесты с pytest
- `data/` - Контекстные файлы (цели, исследования)

### Технологии
- Python 3.10+
- Async/await для I/O операций
- Pydantic для валидации конфигурации
- Loguru для логирования
- Pytest для тестирования
- HTTPX для HTTP запросов

### Важные решения
- Все агенты наследуются от `BaseAgent` для единообразия
- Конфигурация через переменные окружения (`.env` файл)
- Обработка ошибок на уровне базового класса агентов
- Retry логика с exponential backoff в HTTP клиенте
- Приоритет: простое, надежное, бесплатное решение (не идеальная архитектура)
