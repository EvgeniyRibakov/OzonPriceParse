# Ozon Price Parser

Автоматизированный парсер цен с Ozon Seller через браузерную автоматизацию.

> 📖 **Новое устройство?** См. [SETUP_NEW_DEVICE.md](SETUP_NEW_DEVICE.md) - подробная инструкция по настройке с нуля.  
> 🔧 **Специфичные настройки?** См. [DEVICE_SPECIFIC_CONFIG.md](DEVICE_SPECIFIC_CONFIG.md) - список всех настроек, привязанных к устройству.

## Описание

Проект автоматизирует процесс входа в личный кабинет Ozon Seller, прохождения двухфакторной аутентификации и скачивания отчета с ценами товаров в формате XLSX.

## Особенности

- ✅ Полная визуализация процесса в браузере
- ✅ Имитация человеческого поведения с задержками
- ✅ Интерактивный ввод кодов 2FA
- ✅ Подробное логирование всех действий
- ✅ Обработка ошибок с остановкой и уведомлением
- ✅ **Telegram бот для управления парсером**
- ✅ Автоматическая отправка результатов в Telegram
- ✅ Гайд по установке прямо в боте

## Требования

- Python 3.10+
- Selenium (ChromeDriver устанавливается автоматически через webdriver-manager)
- Google Chrome браузер

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd OzonPriceParse
```

2. Создайте виртуальное окружение:
```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/Mac
source venv/bin/activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл `.env` на основе `env.example`:
```bash
# Windows
copy env.example .env
# Linux/Mac
cp env.example .env
```

5. Настройте `.env` файл:
   - `PHONE_NUMBER` - ваш номер телефона для входа в Ozon Seller
   - `TELEGRAM_BOT_TOKEN` - токен бота (получите у @BotFather)
   - `TELEGRAM_BOT_PASSWORD` - пароль для доступа к боту

## Настройка

Отредактируйте файл `.env`:

```env
# Ozon Seller настройки
OZON_START_URL=https://seller.ozon.ru/app/products?token=YOUR_TOKEN
PHONE_NUMBER=+79966444210

# Задержки (в секундах) для имитации человеческого поведения
DELAY_BEFORE_CLICK=1.5
DELAY_AFTER_CLICK=2.0
DELAY_BEFORE_TYPE=0.8
DELAY_AFTER_TYPE=1.2
DELAY_BETWEEN_KEYS=0.1
DELAY_PAGE_LOAD=3.0

# Профиль Chrome для сохранения авторизации (опционально)
# Раскомментируйте и укажите путь к папке User Data Chrome
# Windows: C:\Users\ВашеИмя\AppData\Local\Google\Chrome\User Data
# Linux: ~/.config/google-chrome
# macOS: ~/Library/Application Support/Google/Chrome
# CHROME_USER_DATA_DIR=C:\Users\ВашеИмя\AppData\Local\Google\Chrome\User Data
# CHROME_PROFILE_NAME=Default
```

### Сохранение авторизации через профиль Chrome

Чтобы не сканировать QR-код каждый раз, можно использовать существующий профиль Chrome:

1. **Найдите путь к папке User Data Chrome:**
   - Windows: `C:\Пользователи\ВашеИмя\AppData\Local\Google\Chrome\User Data`
   - Или: `C:\Users\ВашеИмя\AppData\Local\Google\Chrome\User Data`
   - Linux: `~/.config/google-chrome`
   - macOS: `~/Library/Application Support/Google/Chrome`

2. **Определите имя папки профиля:**
   
   **Способ 1 (рекомендуется):**
   - Откройте Chrome с нужным профилем (например, "Евгений Рыбаков")
   - В адресной строке введите: `chrome://version/`
   - Найдите строку "Путь к профилю" или "Profile Path"
   - Там будет указано что-то вроде: `C:\...\User Data\Profile 1`
   - Имя папки профиля — это последняя часть пути: `Profile 1`, `Profile 2` и т.д.
   
   **Способ 2:**
   - Откройте папку `User Data` в проводнике
   - Там будут папки: `Default`, `Profile 1`, `Profile 2` и т.д.
   - Чтобы понять, какая папка соответствует вашему профилю:
     - Откройте файл `User Data\Local State` в текстовом редакторе
     - Найдите имя вашего профиля (например, "Евгений Рыбаков")
     - Рядом будет указано имя папки (например, "Profile 1")
   
   **Важно:** Имя папки — это `Profile 1`, `Profile 2` и т.д., а НЕ отображаемое имя пользователя!

3. **Добавьте в `.env`:**
   ```env
   CHROME_USER_DATA_DIR=C:\Пользователи\fisher\AppData\Local\Google\Chrome\User Data
   CHROME_PROFILE_NAME=Profile 1
   ```
   (Замените `Profile 1` на ваше реальное имя папки профиля)

4. **Важно:** Перед первым запуском:
   - Откройте Chrome с этим профилем (например, "Евгений Рыбаков")
   - Авторизуйтесь на Ozon Seller вручную один раз
   - Закройте Chrome полностью
   - Теперь скрипт будет использовать сохранённую сессию

⚠️ **Внимание:** Не запускайте Chrome вручную одновременно с запущенным скриптом, иначе возникнет конфликт доступа к профилю.

## Использование

### Запуск через Telegram бот (рекомендуется)

1. Настройте бота в `.env`:
   ```env
   TELEGRAM_BOT_TOKEN=your_bot_token_here
   TELEGRAM_BOT_PASSWORD=your_password_here
   ```

2. Запустите бота:
   ```bash
   python run_bot.py
   ```

3. Найдите вашего бота в Telegram и отправьте `/start`

4. Используйте команды:
   - `/parse` - Запустить парсинг
   - `/status` - Статус последнего запуска
   - `/logs` - Последние логи
   - `/download` - Скачать последний файл
   - `/guide` - Гайд по установке с нуля
   - `/settings` - Текущие настройки
   - `/logout` - Выйти из аккаунта

### Запуск напрямую (без бота)

Запустите скрипт:

```bash
python -m src.main
```

Или через run.py:

```bash
python run.py
```

## Процесс работы

1. Запуск браузера (видимый режим, с профилем Chrome если настроен)
2. Переход по начальной ссылке
3. Если профиль не настроен:
   - Нажатие кнопки "Войти" (если требуется)
   - Ввод номера телефона
   - Вход по QR-коду или запрос кода из пуш-уведомления
   - Обработка дополнительной проверки (если требуется)
4. Нажатие кнопки "Скачать шаблоны"
5. Выбор шаблона "Цены товаров"
6. Нажатие кнопки "Скачать"
7. Ожидание 30 секунд и открытие скачанного файла XLSX
